# Aşkitom ❤️

Kamran-dan sənə sevgi ilə hazırlanmış kiçik mobil tətbiq.

## Bölmələr
- **Günün ürək sözü:** hər gün dəyişən sevgi mesajı.
- **Yemək:** orijinal siyahıdakı 24 ayrı yeməkdən təsadüfi seçim.
- **Serial:** Yeraltı və Sevdiyim sənsin üçün YouTube axtarış keçidləri.
- **Moda və Uşaq:** Temu kateqoriya keçidləri.

## Quraşdırma
Bu qovluqdakı bütün faylları və `assets` qovluğunu GitHub reposunun kökünə yükləyin. **Settings → Pages → Deploy from a branch → main → /(root)** seçin.

Mobil telefonun Chrome brauzerində sayt açıldıqda menyudan **Install app / Ana ekrana əlavə et** seçmək olar.

Qeyd: Serial bölüm bildirişləri, qiymətli məhsul siyahıları və yemək şəkillərinin avtomatik internetdən axtarışı hələ qoşulmayıb.
